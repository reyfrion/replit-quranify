Build a **fully functional, deployable web application** called **Quranify** — a Quran memorization (Hifzh) tracking platform with clean UI, gamification, and community features.

The app must be simple, responsive, and ready to run immediately (no complex setup).

---

# 🎯 CORE GOAL

Help users build a consistent Quran memorization habit through:

* daily tracking
* streak system
* leaderboard
* simple and motivating UX

---

# 🛠️ TECH REQUIREMENTS

* Use **Node.js + Express** for backend
* Use **vanilla HTML, CSS, JavaScript** (no heavy frameworks)
* Store data in a local JSON file (for MVP)
* Serve frontend from `/public`
* App must run with:

  ```
  node server.js
  ```
* Must be deployable in Replit

---

# 📁 PROJECT STRUCTURE

```
/project
  server.js

  /public
    index.html
    style.css
    app.js
```

---

# 🗄️ DATABASE STRUCTURE (database.json)

```
{
  "users": [
    {
      "id": 1,
      "name": "User",
      "total_ayat": 0,
      "streak": 0,
      "last_active": null
    }
  ],
  "hafalan": []
}
```

---

# ⚙️ BACKEND FEATURES

### 1. GET /data

Return all database content

### 2. POST /add

Add new hafalan entry:

* surah
* ayah_start
* ayah_end

Logic:

* calculate total ayat:

  ```
  total = ayah_end - ayah_start + 1
  ```
* update:

  * hafalan list
  * user's total_ayat

---

# 🔥 STREAK SYSTEM (IMPORTANT)

When user submits hafalan:

* If last_active == yesterday → streak +1
* If last_active == today → keep streak
* Else → reset streak to 1

Update:

* last_active = today
